# Howling-Moon (Unofficial Port)

This is an unofficial port of the Howling-Moon mod to **NeoForge 1.21.1**. It integrates mechanics from both the 1.7.10 and 1.12.2 versions.

### ⚠️ Notice to the Original Author
This port utilizes assets (textures, sound effects, etc.) from the original mod. Unfortunately, we were unable to contact the original author due to their sudden disappearance, which prompted us to proceed with this port. 

**If you are the original author and do not consent to this port, please contact us immediately.** We will promptly remove the download links and take down the mod. We sincerely apologize for any inconvenience this may cause.

### 🛠️ Commands

- `/werewolf true` - Transform into a werewolf (use `/werewolf false` to revert).
- `/werelevel <number>` - Set your werewolf level (e.g., `/werelevel 5`).
- `/wereprogress <0-8> <-1|0|1>` - Set quest progress and alignment.
  - **Example:** `/wereprogress 5 0` (Neutral), `-1` (Feral), `1` (Calm).
  - *Note: Quest progress refers to the progression in the werewolf dimension from the 1.12.2 version (which triggered every 5 levels). Since this dimension has been removed, quest progress can now only be adjusted via this command.*
